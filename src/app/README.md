## 🎯 What is bixtx.com?

bixtx.com is a next-generation, AI-powered remote access and device management platform designed to surpass existing solutions like TeamViewer and AnyDesk. The system consists of two distinct software types working together:

### 🔵 Software A: Link Software (Monitoring Agent)
- **Status**: ⚠️ Specification Complete - Development Needed
- **Purpose**: Lightweight agent installed on devices to be monitored
- **Platforms**: Windows, macOS, Linux, Android, iOS
- **Interface**: Minimal (system tray only)

### 🟢 Software B: App Platform (Control Interface)
- **Status**: ✅ Complete - Ready to Export
- **Purpose**: Full-featured control interface for admins
- **Platforms**: Web (primary), Desktop, Mobile
- **Interface**: Rich dashboard with advanced features

## 🛠️ Technology Stack

### Software B (App Platform) - Built & Ready
```
Frontend Framework:     React 18.2
Language:              TypeScript 5.2
Styling:               Tailwind CSS v4
Build Tool:            Vite 5.0
UI Components:         Radix UI
Icons:                 Lucide React
State Management:      React Context API
Charts:                Recharts
Notifications:         Sonner
Forms:                 React Hook Form
```

### Software A (Link Software) - Planned
```
Desktop:               Electron + Node.js
Android:               Kotlin + Jetpack
iOS:                   Swift + SwiftUI
WebRTC:                Native WebRTC APIs
Database:              SQLite (local)
Encryption:            AES-256-GCM
```

### Backend Infrastructure - Planned
```
Signaling Server:      Node.js / Go
API Server:            Node.js / Express
Database:              PostgreSQL / MongoDB
File Storage:          AWS S3 / Azure Blob
TURN/STUN:             Coturn
Authentication:        JWT + OAuth2
```
