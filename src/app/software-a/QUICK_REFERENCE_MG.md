## ⚡ Quick Start

```bash
# Install
sudo dpkg -i bixtx-link-mg_1.0.0_amd64.deb

# Configure
sudo nano /etc/bixtx-link/.env

# Start
sudo systemctl start bixtx-link

# Check Status
bixtx-link --status
```

## 🔍 Troubleshooting

| Problem | Quick Fix |
|---------|-----------|
| Service won't start | `sudo systemctl restart bixtx-link` |
| Protection inactive | `bixtx-link --reinit-protection` |
| Channels failed | Check firewall, test with `--test-channels` |
| High CPU usage | Increase check intervals in .env |
| Permissions denied | Grant required OS permissions |
