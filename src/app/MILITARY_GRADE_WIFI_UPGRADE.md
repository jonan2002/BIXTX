## 📱 USAGE WORKFLOW

### Admin Dashboard → Network Discovery Tab:

1. **Enable WiFi Discovery**
   - Toggle "WiFi Discovery" switch

2. **Scan Networks**
   - Click "Deep Network Scan"
   - Wait 1.5s for RF spectrum analysis
   - View all detected networks

3. **Connect to Network**
   - Click "Swift Connect" on target network
   - Enter password if secured (WPA2/WPA3)
   - Click "Execute Swift Connect"
   - Connection established in < 1.2s

4. **View Devices**
   - Click "View Targets" on connected network
   - See all devices with threat analysis
   - View IP, MAC, manufacturer, vulnerabilities

5. **Pair Device**
   - Click "Secure Link" on target device
   - AES-256 tunnel established in < 0.8s
   - Device shows "PAIRED" status

6. **Deploy Remote Control**
   - Click "Deploy C2" on paired device
   - Session created and added to Sessions panel
   - Navigate to Sessions tab for full control
